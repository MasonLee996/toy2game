# 小院建造家 · Garden Builder

单人 3D 真砖玩具建造：从一块红砖开始，抹浆、错缝砌墙、预留门窗、逐片铺瓦，再砌菜畦和鱼池。自由创作为主，附带可选图纸提示与五项工序目标。

## 玩法与数字版改编

- 24 × 24 个半砖定位格，一格为半块标准砖的平面宽度；每皮砖对应一个高度步进，最多 17 皮。整砖 2 × 1 格、半砖 1 × 1 格、过梁 4 × 1 格；门框 2 × 1 × 5 皮，窗框 2 × 1 × 3 皮。框内空洞保留，不能在洞内堆砖。
- 每次只放一块砖或一件配件。砖与过梁默认自动抹浆：双击／双触或点击放置后，泥刀刮平砂浆，再落下一块砖。可关闭自动抹浆，分两步操作；改变位置、旋转或材料需重新抹浆。动画期间锁定重复操作，减少动态效果偏好使用短暂静态反馈。灰白砂浆接缝在模型中可见。材料不限供应，每个地块最多放置 1500 件以控制绘制开销；没有搅拌配比、干燥等待或刚体坍塌模拟。
- 高度自动判定，不需要手选：空地从地面开始，已有材料上自动叠高，瓦片按相邻高边搭接。采用占格碰撞与支撑检查；不会穿过已有部件寻找底层空位，悬空或越界会提示原因。
- 单片斜瓦占 2 × 2 格，高差一皮；沿瓦片低边方向从檐口逐片搭接，朝向由旋转决定。屋脊瓦也是单独配件，不提供完整屋顶模块。
- 普通砖、半砖和框架底面需有下层支撑；过梁两端有支撑即可跨洞。斜瓦可由檐墙支撑或衔接下层同向瓦片高边。屋脊瓦需瓦片／支撑面托住。支撑检查是网格建造简化，不代表真实工程受力模型。
- 泥土与菜苗需先砌出 2 × 2 格内空的四边，鱼池内胆需先砌出 4 × 2 格内空的四边。不能一键生成砖砌菜园或鱼池。白栅栏保留为独立配件。
- 五项可选工序目标：80 块砖、至少一个门框和窗框、16 片灰瓦及 4 片脊瓦、两处砖围菜畦、一处砖围鱼池。目标统计材料工序，不自动评判建筑美观，也不强制作品与参考图纸一致。完成后可验收、继续创作或再次开局。
- 示例图纸提供 172 件材料的合法逐块顺序；“下一块图纸提示”只选择材料与位置，不代替放置。勾选连续提示后每放一件就定位下一件；手动选位置、材料或旋转就退出连续提示；自由改建占用图纸位置时跳过当前不能放置的提示。图纸是项目原创的小院示例，不是实体商品原厂说明。
- 默认开局已铺 27 件基础砖和门框，其余由玩家逐块完成。设置可改为空白地块；编辑草稿、取消、确认新局彼此隔离。独立“新的一局”沿用生效配置，未完成且有编辑进度时须确认。
- 拆除会校验依赖，先取上层材料或移除内胆／泥土，再拆其支撑。最多保存 60 步撤销与重做；作品和有效设置自动保存。存档键 `garden-builder-save-v2`：早期未发布的整墙原型存档不兼容，明确以新地块重新开始。损坏、未知版本或不可用的存储不阻止游玩。

## 操作、工程与资源

点击材料、单击／轻触定位格预览，预览旁出现 44px 的旋转、✓ 确认和 × 取消按钮；旋转每次转 90° 并立即重算落点与支撑，拆除时隐藏旋转；确认执行放置／拆除，取消清除预览且不改作品。也可双击／双触透明预览原位放置（即使预览已在高处，也不会重新投影到地面），也可使用放置按钮。建造显示泥刀，拆除显示拆除锤及橙色工具提示；选中材料会显示橙色半透明高亮，双击高亮拆除。拖动旋转视角，双指移动与缩放、鼠标右键拖动平移、滚轮缩放；工具提供俯视、复位、放大缩小，高度只读显示自动结果。精确定位提供行、列的大触控控件，高度仍由下方材料决定。R 旋转，方向键定位，Enter 执行当前抹浆／放置，Delete 切换拆除，Ctrl/Cmd+Z 撤销，Shift+Ctrl/Cmd+Z 重做（输入控件和弹窗内不拦截）。

暂停、弹窗和后台时锁定建造、停止抹浆动画、游鱼和音效；恢复后继续当前工序，确认新局或销毁场景会取消旧工序。全屏按浏览器能力与权限显示，兼容成对的旧 Safari 接口，状态由浏览器事件同步，不重置作品或视角。

Vite + 严格 TypeScript + Three.js。规则位于 `src/rules.ts`，历史与存档在 `src/game.ts`，模型在 `src/models.ts`，渲染和手势在 `src/scene.ts`，UI 在 `src/main.ts`。模型、缩略图与音效由代码生成，图标使用 lucide，中文字体使用本地 Noto Sans SC（SIL Open Font License，许可证在 `public/fonts/noto-sans-sc-OFL.txt`）；无远程素材。封面截取实际游戏。纯静态本地游戏，无账号或联机。

## 运行与验证

从仓库根目录执行：

```sh
npm install
npm test --workspace games/garden-builder
npm run dev
GAME_URL=http://localhost:5173/games/garden-builder/ npm run test:browser --workspace games/garden-builder
GAME_URL=http://localhost:5173/games/garden-builder/ node games/garden-builder/tests/fullscreen-check.mjs
GAME_ID=garden-builder npm run covers
npm test
npm run build
npm run test:e2e
```

生产测试前停止开发服务。`CHECK_WEBKIT=1` 可加测 WebKit，`CHECK_ENGINE=webkit` 可只运行 WebKit 场景与全屏回归；手势专项也支持 `CHECK_ENGINE=webkit`，真实多点缩放通过 Chrome CDP 验证。子目录使用 `SITE_BASE=/toy2game/` 构建与预览。截图存放于 `artifacts/garden-builder/`。`window.__garden` 仅开发模式提供。浏览器设备模拟不能代替真实 iPad Safari 硬件测试。
